# 📚 Домашняя практическая работа по T-SQL от 01.10.2026 (dz011026)

## 🎯 Общее описание проекта
В данном каталоге представлено выполнение домашнего задания, направленного на углубленное изучение механизмов декларативной целостности данных, связей между сущностями и манипулирования выборками в среде **Microsoft SQL Server**. Основная цель работы — построение логически корректной реляционной модели и написание оптимизированных запросов на языке **Transact-SQL (T-SQL)**.

---

## 📂 Подробный состав и структура каталога
* **`dkkddkdk`** — главный исполняемый скрипт сценария базы данных. Содержит структурированный код, разбитый на логические блоки с помощью управляющих инструкций (таких как `GO`).
* **`Снимки экрана (0-5)`** — доказательная база тестирования (визуальный аудит работы скриптов). Каждый снимок экрана фиксирует состояние таблиц до и после выполнения транзакций, а также сообщения компилятора об успешном завершении операций (`Commands completed successfully`).

## 🛠️ Технический стек и инструменты разработки
* **СУБД:** Microsoft SQL Server (MS SQL Server)
* **Среда разработки:** SQL Server Management Studio (SSMS) / Azure Data Studio
* **Язык запросов:** Transact-SQL (T-SQL) с использованием стандартов ANSI SQL

## 🚀 Детальный перечень реализованной логики

### 1. Архитектура и DDL (Data Definition Language)
* **Проектирование таблиц:** Описание сущностей, выбор оптимальных типов данных (целочисленные `INT`, строковые переменной длины `VARCHAR`/`NVARCHAR`, временные метки `DATETIME`).
* **Обеспечение целостности данных (Constraints):**
  * Первичные ключи (`PRIMARY KEY`) для уникальной идентификации кортежей.
  * Внешние ключи (`FOREIGN KEY`) с правилами ссылочной целостности для связывания таблиц типа «один-ко-многим».
  * Ограничения на пустые значения (`NOT NULL`) для критически важных полей.

### 2. Манипулирование данными и DML (Data Manipulation Language)
* Наполнение таблиц сгенерированными тестовыми данными через инструкции `INSERT INTO`.
* Выборка информации с использованием фильтрации `WHERE`, сортировки `ORDER BY` и группировки данных с агрегатными функциями.

### 3. Тестирование и верификация
* Проверка работы ограничений на практике (попытки вставки некорректных данных для валидации триггеров ошибок СУБД).
* Фиксация результирующих сеток (Result Grid) для демонстрации корректности выборок.

## 💡 Как запустить проект локально
1. Убедитесь, что у вас установлен **MS SQL Server** и утилита **SSMS**.
2. Откройте файл `dkkddkdk` в среде SSMS.
3. Подключитесь к вашему локальному или удаленному серверу баз данных.
4. Выделите весь код (сочетанием клавиш `Ctrl + A`) и нажмите клавишу **`F5`** (или кнопку *Execute* на панели инструментов) для развертывания схемы.
