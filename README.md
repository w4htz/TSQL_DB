# 🗄️ Базы данных и язык Transact-SQL (T-SQL)

Репозиторий представляет собой структурированное цифровое портфолио, содержащее учебные материалы, лабораторные работы, домашние задания и теоретические конспекты, разработанные в процессе освоения СУБД **Microsoft SQL Server**.

---

## 🎯 Цели и ключевые задачи проекта
* **Систематизация кода:** Хранение всех написанных SQL-скриптов и решений в едином, логически упорядоченном пространстве.
* **Архивация прогресса:** Фиксация результатов выполнения заданий с помощью детальных скриншотов отладки и верификации запросов.
* **Контроль знаний:** Демонстрация навыков проектирования баз данных, обеспечения декларативной целостности и автоматизации логики СУБД.

---

## 📂 Глобальная архитектура и структура репозитория

Каталог проекта строго распределен по трем функциональным направлениям:

### 1. 📝 `Домашняя Работа/`
Архив для самостоятельных заданий повышенной сложности. Каждый подкаталог содержит исполняемый файл `.sql` и скриншоты верификации кода.
* `dz1` & `dz2` — Инициализация реляционной структуры баз данных, базовые DDL-сценарии и манипуляции с выборками DML.
* `dz240926` & `dz250926` — Комплексные выборки данных, многотабличные соединения (`JOIN`), фильтрация и агрегация.
* `dz011026` & `dz111026` — Проектирование сложных ограничений целостности данных, связей и валидация схем.
* `triggerdz` — Практическая разработка активных триггеров (`AFTER INSERT/UPDATE/DELETE`) с обработкой системных таблиц `inserted`/`deleted`.

### 2. 📂 `Практическая работа/`
Скрипты, написанные во время очных практических занятий, аудиторных пар и выполнения лабораторных работ.
* Содержит папки `021026PRACTIKA2PARA`, `071026para`, `081026para`, `091026практика` и `пара`.
* Фокус разделов: разбор практических кейсов СУБД, написание "живого" кода совместно с преподавателем и оперативное исправление синтаксических ошибок.

### 3. 📦 `Теория/`
База знаний проекта, содержащая лекционные материалы, файлы дистанционного обучения и архитектурные скрипты.
* Дистанционные занятия (`2509dist`, `110826dist2`, `110926dist`).
* Изучение расширенных концепций программирования СУБД (`polzovatelskiefunkciiilogika`, `triger1`, `CONSPECTF2`).

## 🛠️ Используемый стек технологий
* **Система управления базами данных:** Microsoft SQL Server (MS SQL Server)
* **Инструменты администрирования и разработки:** SQL Server Management Studio (SSMS) / Azure Data Studio
* **Язык запросов:** Transact-SQL (T-SQL) стандарта ANSI-SQL

---

## 🚀 Основные компетенции и реализованная логика

В ходе наполнения репозитория были успешно освоены и применены на практике следующие механизмы:
1. **Проектирование схем (DDL):** Развертывание реляционных баз данных с использованием ограничений `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `CHECK`.
2. **Анализ и манипуляция множествами (DML):** Построение производительных запросов, использование группировок (`GROUP BY`), условий фильтрации и подзапросов.
3. **Программирование баз данных:** Создание автоматических триггеров для контроля сложной бизнес-логики и пользовательских функций.
4. **Тестирование и аудит:** Проведение пошаговой отладки и верификации логов СУБД с фиксацией графических отчетов (Result Grid).

## 💡 Как запустить любой проект из репозитория
1. Склонируйте данный репозиторий на локальную машину:
   ```bash
   git clone https://github.com
   ```
2. Откройте интересующий вас `.sql` файл в среде **SSMS**.
3. Подключитесь к локальному экземпляру вашего SQL-сервера.
4. Нажмите горячую клавишу **`F5`** для компиляции и выполнения скрипта сценария.
