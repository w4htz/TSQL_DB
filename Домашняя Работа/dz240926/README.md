# 📊 Домашняя практическая работа по T-SQL от 24.09.2026 (dz240926)

## 🎯 Введение и цели проекта
Данный модуль содержит комплексное выполнение домашнего задания, направленного на углубление навыков написания аналитических и манипуляционных запросов на языке **Transact-SQL (T-SQL)** в среде Microsoft SQL Server.

Основная цель работы — построение корректной логики выборки данных из нескольких таблиц, агрегация показателей бизнес-логики и проведение детального визуального аудита работы СУБД при обработке множественных записей.

## 🚀 Реализованный функционал и логические слои

### 1. Проектирование реляционных связей (DDL)
* Конфигурация схемы таблиц со строгим соблюдением ограничений целостности данных (`NOT NULL`, `PRIMARY KEY`, `FOREIGN KEY`).
* Подбор типов данных для корректного маппинга текстовых, числовых полей и связующих идентификаторов (ID).

### 2. Продвинутые выборки и манипуляция данными (DML)
* Реализация сценариев многотабличных запросов и фильтрации результирующего набора строк с помощью предикатов `WHERE`.
* Использование агрегатных функций и сортировки данных (`ORDER BY`) для формирования наглядных отчетов.

### 3. Пошаговое тестирование и верификация
* Контроль выполнения транзакций на каждом этапе (что зафиксировано в детальной серии скриншотов).
* Проверка корректности работы ограничений базы данных при добавлении тестовых наборов записей.
