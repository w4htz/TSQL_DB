# 📚 Домашняя работа №1 по T-SQL (dz1)

## 🎯 Общее описание
В данном каталоге представлено выполнение первой домашней работы по проектированию баз данных и написанию базовых скриптов на языке **Transact-SQL (T-SQL)**. Работа включает в себя создание структуры таблиц, определение типов данных и проверку базовых операций манипулирования данными.

---

## 📂 Структура и состав папки
* **`script.sql`** — основной исполняемый файл скрипта T-SQL. Содержит блоки кода создания таблиц (DDL) и тестовые запросы.
* **`Снимки экрана (22.09.2026)`** — подтверждение успешного выполнения и отладки кода. Скриншоты фиксируют корректный вывод данных в Result Grid среды SSMS и отсутствие ошибок компиляции.

---

## 🛠️ Системное окружение
* **СУБД:** Microsoft SQL Server
* **Инструмент разработки:** SQL Server Management Studio (SSMS)
* **Языковой стандарт:** T-SQL

## 🚀 Что было реализовано
1. **Инициализация структуры БД:** Написание запросов для создания таблиц, выбор оптимальных типов данных для текстовых и числовых полей.
2. **Первичная проверка выборки:** Базовое наполнение таблиц тестовыми строками и написание простых операторов `SELECT` для проверки связей.
