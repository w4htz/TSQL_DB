# 📊 Домашняя практическая работа по T-SQL от 11.10.2026 (dz111026)

## 🎯 Введение и цели проекта
Данный модуль содержит комплексное выполнение домашнего задания, сфокусированного на проектировании реляционных баз данных и написании структурированных скриптов на языке **Transact-SQL (T-SQL)**. 

Основной упор в работе сделан на обеспечение целостности бизнес-логики на уровне СУБД, оптимизацию обработки данных, а также валидацию созданных алгоритмов в изолированной среде тестирования.

В каталоге размещены следующие ресурсы:
* **`dz111026`** — центральный скрипт сценария базы данных. Содержит чистый структурированный SQL-код с делением на логические транзакционные блоки.

## 🚀 Реализованный функционал и логические слои

### 1. Моделирование структуры данных (DDL)
* Развертывание табличных пространств со строгим контролем типов данных для минимизации избыточности хранения информации.
* Настройка связей «один-ко-многим» и ограничений ограничений (`FOREIGN KEY`, `PRIMARY KEY`), предотвращающих появление висячих ссылок и логических аномалий.

### 2. Манипуляция и выборка данных (DML)
* Реализация точечных запросов выборки с использованием предикатов фильтрации данных (`WHERE`).
* Построение агрегированных отчетов с применением функций группировки, позволяющих анализировать срезы данных СУБД.

### 3. Отладка и нагрузочное тестирование
* Проведение ручного тестирования граничных сценариев вставки данных.
* Фиксация логов выполнения скриптов для подтверждения стабильности работы схемы.
