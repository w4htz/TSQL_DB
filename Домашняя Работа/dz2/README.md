# 📚 Домашняя практическая работа по T-SQL №2 (dz2)

## 🎯 Введение и цели проекта
Данный модуль содержит выполнение второй домашней работы, развивающей навыки проектирования реляционных баз данных и построения SQL-скриптов повышенной сложности на языке **Transact-SQL (T-SQL)**. 

Основная цель работы — глубокое освоение механизмов манипулирования табличными данными, детальная настройка ограничений сущностей, а также валидация выполнения сложных транзакционных запросов в среде MS SQL Server.

---

## 📂 Структура и состав каталога
Внутри папки находятся следующие отчетные ресурсы:
* **`script..sql`** — основной исполняемый сценарий базы данных T-SQL, содержащий структурированную логику DDL/DML запросов.
* **`Снимки экрана от 22.09.2026`** — визуальные лог-файлы отладки. Скриншоты подтверждают корректное выполнение блоков кода, успешную вставку/изменение записей и точное отображение результирующих сеток (Result Grid).

---

## 🛠️ Технологический стек проекта
* **СУБД:** Microsoft SQL Server (MS SQL Server)
* **Среда администрирования:** SQL Server Management Studio (SSMS)
* **Диалект кода:** Transact-SQL (T-SQL)

---

## 🚀 Реализованный функционал и логические слои

### 1. Нормализация и расширение структуры (DDL)
* Развертывание реляционной модели с жестким контролем ссылочной целостности через механизмы ограничений (`PRIMARY KEY`, `FOREIGN KEY`).
* Конфигурация полей под оптимальное распределение памяти на сервере баз данных с учетом типов и размеров данных.

### 2. Управление данными и аналитические выборки (DML)
* Наполнение таблиц сложными наборами связанных тестовых данных с помощью инструкций `INSERT INTO`.
* Построение комплексных запросов для извлечения информации с использованием расширенных предикатов фильтрации `WHERE`, сортировки `ORDER BY` и группировки данных.

### 3. Комплексное тестирование кода
* Эмуляция выполнения сценариев для проверки корректности связей между таблицами.
* Проверка логов СУБД на отсутствие логических коллизий при обработке строк.

---

## 💡 Инструкция по локальному развертыванию
1. Перейдите в каталог `dz2` и откройте файл `script..sql` в вашей SSMS.
2. Подключитесь к рабочему экземпляру SQL Server.
3. Выделите скрипт целиком (`Ctrl + A`) и запустите компиляцию нажатием кнопки **Execute** или клавиши **`F5`**.
4. Сверьте полученный результат вывода таблиц со скриншотами отладки в этой папке.
