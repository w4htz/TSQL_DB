# 📊 Домашняя практическая работа по T-SQL от 25.09.2026 (dz250926)

## 🎯 Введение и цели проекта
Данный модуль содержит выполнение домашнего задания по проектированию баз данных и написанию скриптов манипулирования данными на языке **Transact-SQL (T-SQL)** в среде Microsoft SQL Server.

Основная цель работы — закрепление навыков построения реляционных связей, реализации сложных DML-операций, проверки логических ограничений целостности и фиксации результатов отладки запросов.

---

## 📂 Структура и состав каталога
Внутри папки находятся следующие отчетные ресурсы:
* **`dz250926`** — основной исполняемый сценарий базы данных T-SQL, содержащий структурированную программную логику.
* **`Снимки экрана (4 шт.)`** — графическая верификация работы скриптов. Скриншоты подтверждают успешное прохождение всех этапов вставки и выборки данных, вывод результирующих сеток (Result Grid) и отсутствие синтаксических ошибок в интерфейсе SSMS.

## 🚀 Реализованный функционал и логические слои

### 1. Архитектура таблиц и декларативная целостность (DDL)
* Создание реляционных сущностей с жестким контролем ссылочной целостности через механизмы ограничений (`PRIMARY KEY`, `FOREIGN KEY`).
* Использование ограничений на пустые значения (`NOT NULL`) для обеспечения корректности хранения бизнес-информации.

### 2. Манипуляция данными и фильтрация выборок (DML)
* Первичное наполнение табличной структуры тестовыми наборами данных с помощью инструкций `INSERT INTO`.
* Построение запросов извлечения информации с использованием предикатов фильтрации `WHERE` и сортировки `ORDER BY`.

### 3. Тестирование и верификация кода
* Контроль выполнения транзакций и операций на каждом этапе (что зафиксировано в серии скриншотов отладки).
* Валидация работы созданной схемы базы данных на локальном экземпляре сервера.
